# ボス再出現（2026-11-16）

## 変更内容

- 撃破済み階層でも、毎探索0.5%・200回目の確定出現を適用する。
- ボス戦後は勝利・敗北・引き分けすべてで該当階の探索回数を0へ戻す。

DBマイグレーション・既存データの一括変更は不要。撃破済みで200回以上の回数が残っている場合、変更後の最初の探索でボスが出る。その戦闘後から0より数え直す。

探索は引き続きログイン必須・POST限定。キャラクターの行ロックとトランザクション、クールタイムによる二重実行防止を維持する。
