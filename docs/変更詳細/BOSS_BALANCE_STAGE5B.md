# ステップ5-B：戦術C2とボス能力値の感度分析

2026-11-17 JST / `feature/boss-balance-stage5b` / 起点main統合済み`abd4bb4`。

## 結論

**魔法職C2はC1から改善したが、今回のボス能力値候補に、そのまま正式採用を勧められる値はない。** 8階AGI900でも全7職業のB/Cが各10/10勝。1階HP128、6階HP13,440も職業別の目標へ届かない。7階INT低減はCの一部を容易にする一方、物理3職のBは0/5のままで、Bが高勝率の職業も残る。5-AのINT低減案は正式反映を保留する。

B約10%（5〜15%）、C約50%（40〜60%）を維持する。Bを弱くして目標へ合わせない。今回の結果は固定キャラクター/職歴/装備への条件付き勝率で、最適戦術・全プレイヤー平均の確定ではない。

## 条件と測定の安全性

- 5-Aで記録した同一profileを使用。B/C1/C2間で種族・Lv・回帰・素値・属性・属性成長重み・装備・永久習得一覧・戦闘開始補正値の一致を自動確認した。
- 1階は0回帰Lv20・継承なし。6階は20回帰・戦闘力5,000。7階は戦闘力約13,380、8階約26,382、12階約83,382。装備は5-Aどおり、1階なし、6階職業別F+5〜+7、7/8/12階F+5。
- 継承ありは職歴を事前固定し2職業各5回で10種類を揃えた条件。B/Cで取得リストを変えない。職歴・取得順・能力値は各manifestのprofileへ保存した。
- 7階94〜97回帰、8階198〜202回帰、12階654〜657回帰は、旧算出器由来の**数値上の評価到達例**。実際の育成時間・素材/Q・転職証の負担は未検証であり、通常プレイヤーの正式推奨回帰数としない。
- 候補値はEnemyのメモリ上のコピーへ単一フィールドだけ設定。DBのEnemyには保存せず、正式値・migration・戦闘計算式・スキル値を変更しない。元値一覧は隔離DBのmigrationから再現した値。
- 各戦闘に実際に渡した能力値/技能を`evaluation_boss`としてJSONLへ記録し、対照値＋指定した1能力の差だけであることを全件検証した。戦闘中は既存のSELECT以外拒否を使用する。

### C2以降の未測定案

C1からの改善はあるため、C2を魔法職の**次の評価基準**にすることを提案する。実プレイヤーの設定を自動変更しない。

### 8階AGI：効果はあるが540/900では勝率を下げられていない

全7職の各B/Cが全候補10/10勝（各Wilson72.2〜100%）。B/Cの14条件等重み平均で、ボス行動は0.61→3.39→5.96回、被ダメージは約14→404→1,490へ増えた。AGIが効いていないのではなく、現在のプレイヤーHP/火力に対して増えた攻撃機会でも倒し切れていない。

ボスは防御/反撃中心の5枠を持つため、行動数増加がそのまま直接攻撃数増加にはならない。AGIは防御効果の期間消費・疲労・反撃機会にも作用する。**900を正式採用すれば目標になるという案は推奨しない。** HP/STR等、別の単一能力を調べる次段階の根拠であり、今回はその値を未測定の確定値として置かない。

### 1階HP：128でも職業間の必要強化量が違う

HP128でBは拳闘士9/10・重戦士9/10・狩人10/10・ウィザード7/10・プリースト5/10・放浪人10/10・暗殺者4/10。Cは順に10/10・10/10・8/10・7/10・9/10・10/10・5/10。

HP増加は決着を遅らせ、ボス平均行動3.64→8.36回、被ダメージ約20→46へ増える。暗殺者Cが50%になっただけでHP128を適正とはしない。暗殺者B40%（16.8〜68.7%）もB目標を上回り、強い職業は100%が残る。全職一律でHPをさらに増やす前に職業別の転落を確認する。

### 6階HP：物理職が高勝率のまま魔法職Bが先に落ちる

HP13,440でも物理5職のB/Cは各5/5、魔法2職のC2も各5/5。Bはウィザード3/5、プリースト2/5へ低下した。5戦のWilsonは広いが、HPのみを上げると弱い側のBへ先に影響する兆候がある。残MP不足を解消する案や、魔法防御にもなるINTの安易な上昇を提案しない。HP+40%を最終値として即採用する根拠もない。

### 7階INT：前段の弱体化候補を保留へ変更

INT1,600→1,440→1,280でも拳闘士/重戦士/狩人Bは全候補0/5。Cは拳闘士3→4→5勝、重戦士2→4→4勝、狩人3→3→3勝。放浪人Bは4勝のまま、暗殺者Bは2勝のまま。ウィザードBは3→3→5勝、プリーストBは3勝のまま。

物理職Bの改善不足と、既に高い魔法職B/放浪人Bの同居があり、一律INT低減では目標へ近づかない職業が残る。**INT1,280を正式弱体化として採用することは勧めない。** 魔法C1の低勝率を根拠にINTを下げる判断は、今回のC2で根拠が変わった。物理Bの順序/回復/バフの機会費用も確認し、Bを意図的に弱くする方向へは変更しない。

## 旧結果の再利用・不確実性

3-Cでは8階AGIの行動差と、5/7階の装備による攻略経路を確認した。5-AではC1の魔法職低勝率が出たが各5戦だった。今回B/C1の同じ条件を新seedで30戦再確認し、C2だけでなくB/C1自体の不確実性も示した。5-A7階魔法Bの0〜1/5と、今回17〜18/30の差を、Bを変更した結果や実装不具合と解釈しない。キャラクター条件とBの枠は一致を検証している。

新旧のcase/seedを無理に合算していない。新旧seedは分離した。既存3-C/5-Aの結果・manifest・ログ・失敗履歴も上書きしない。

各条件5戦で0/5のWilson上限は43.4%、5/5下限は56.6%。10戦でも10/10下限72.2%、30戦でも0/30上限11.4%。多数の条件を見ており、区間には多重比較補正を加えていない。B5〜15%という狭い許容帯への適合や、全育成seedの攻略可能性を保証できない。

## 未測定・未確定とステップ5-Cへの提案

**今すぐ正式反映すべきボス能力値は未確定。候補の正式適用migrationはまだ作らないことを提案する。**

1. 魔法職の評価CをC1からC2へ更新する候補は支持する。ただし実ゲームのプリセットを強制変更せず、Bは維持する。C3は未測定案。
2. 8階はAGI単独540/900を最終値として採用せず、別の単一能力の感度を調べる。1階HP128/6階HP13,440も、今回の値だけで最終目標に到達したとはしない。
3. 7階INT低減の正式反映は保留し、物理Bの初動と魔法B/Cの差を確認する。HP/STR/INT等を同時に変えて原因を曖昧にしない。
4. 次の確認は代表職・境界条件を絞り、必要なら各100戦を計画する。300/1,000戦は別途承認まで行わない。特定職がほぼ勝てない状態を平均で正常扱いしない。
5. 値が絞れてから全7職B/Cを確認し、復元データを保存した正式変更案を提示する。今回の未測定値を採用決定として記載しない。

未測定は、12階の新seed物理職、12階の能力値変更、魔法C1×8階AGI/6階HP/7階INTの候補値、1階のC2（0回帰では資格なし）、C3、異なる装備・種族・育成seed・継承プール、2/3/4/5/9/10/11階の新規測定、到達時間/経済条件。C2×8階AGIは各10戦、C2×6階HP/7階INTは各5戦で**測定済み**なので、未測定と混同しない。
