# ステップ4-B：闘技場の共通スキル戦闘（2026-11-17）

作業ブランチ`feature/skill-inheritance`、開始HEAD`1ca842a`。ステップ4の未コミット実装を保持したまま追加した。通常DBへのmigration適用・削除、Gitのcommit/push/mergeは行っていない。

## 正式仕様と今回の変更

「探索・闘技場は共通のスキル戦闘を使用する」が今回明確化された正式仕様。旧報告`SKILL_INHERITANCE_STEP4.md`の「闘技場は通常攻撃専用を維持」はステップ4時点の未実装範囲を示す履歴であり、恒久的な設計仕様ではない。

挑戦者・マスターの双方に`ArenaSkillActor`を接続した。実キャラクターの種族・装備・現職・永久習得資格・戦術を参照し、同一の`BattleEngine`の実行メソッドを利用する。

- `BattleEngine.initialize_presets()`を抽出し、現職固有＋永久習得の共通認可、最大5枠、戦闘ごとの残回数の初期化を共有する。
- `player_turn()`、`execute_player_skill()`と各職業Mixinをそのまま使用。成功時のみMP/回数を消費して次枠へ移り、発動失敗・MP不足では現枠に留まって通常攻撃。全枠枯渇も通常攻撃。
- パッシブはプリセットに設定した場合のみ有効。回数を消費せず、双方の累積補正・使用予算・スロット位置は独立する。
- 相手の`PlayerCombatant`と実キャラクターの属性名を探索の対象インターフェースへ接続。対象能力は相手のスキル実行器を介して取得し、現在のバフ/デバフ・ST・装備・種族補正を反映する。
- 毒・睡眠・麻痺、DEX低下、回復、防御バフ、反射、反撃、種族パッシブ、装備効果は共通実装へ委譲。行動開始時の状態異常は1回だけ処理する。反撃/反射は追加ゲージ行動ではなく、再反撃防止も既存共通処理を使用する。
- 旧闘技場の通常攻撃の重複計算を除去。既存の単発通常攻撃APIは共通実装への委譲として残した。旧状態辞書APIもCombatantの同じ状態を参照し、二重に保存しない。

闘技場の`run()`、行動ゲージの制御、勝敗形式、結果キー、時系列スナップショットは維持する。探索用の`run()`やEXP/報酬処理をPvPへ流用していない。探索のダメージ式・スキル倍率・ボス値・成長式は変更していない。

## 統一に伴って変わる旧挙動

1. 闘技場の麻痺は従来の必ず行動不能から、探索どおり50%判定になる。残期間は自分の行動で消費。
2. 装備の衰弱はCombatantの1%DEX低下を参照し、探索の敵側行動終了と同様、skipでもその行動終了時に解除する。ポイズンダガー由来の3%低下とは別に保持する。
3. 通常攻撃にも探索に既存の属性一致判定・睡眠時補正・行動開始の種族パッシブ・行動終了バフ/パッシブを使用する。探索にある無属性の扱いを独自に修正していない。旧闘技場の特殊能力倍率テストでは、得意属性補正を除外して倍率だけを検証するよう準備を変更した。

これらは今回の「探索と統一」という明示指示に基づく差異。未完成のフロストアーマー・浄化・リザレクについて軽減率や効果を追加していない。全35種類は共通の現在の実装で実行されることを検証し、未完成部分の完成を保証しない。

## 行動ゲージ・ST・戦闘不能

開始時最高有効AGIを固定基準とし、共通`calculate_gauge_gain`と`action_priority`を使用。毎ループの現在AGIには疲労・歩行者・エルフ・自由等が反映される。100消費・余剰繰越、各人1ループ最大1回、同時到達時の既存優先順を維持する。

STは両者100から開始（最大ST以下）。共通`finish_player_action()`で通常/スキル行動は5消費、睡眠・麻痺・毒死・一撃必殺反動などのskipは消費しない。STはDB保存/持越ししない。

毒で行動前に倒れた者はスキルを使わず、MP/回数も消費しない。先の攻撃で倒された参加者は、そのループに行動可能でも後続行動しない。相手が多段攻撃や反射/反撃で戦闘不能になった場合は共通実装の打切り判定を使う。

**両者HP0は従来の闘技場と同じく挑戦者勝利。** 防衛者HP0を先に判定する既存の優先順であり、探索の相手全滅優先とも対応する。反射で実際に両者0となるテストを追加した。相討ちを引分とする変更は行っていない。内部のオーバーキルは共通処理のまま扱い、闘技場の公開HP・結果・時系列では0以上に表示する。

## ArenaState・報酬・認可

`arena_services.py`と戦闘ビュー/認可には変更なし。

- 開始HP/MPは両者のArenaState。Character本体の通常HP/MPを消費しない。
- 挑戦者勝利：マスター交代、旧マスターは最大100まで1階上へ移動し、両者のArenaState HP/MPを回復。
- 敗北：挑戦者は最低1階まで2階下降。引分：最低1階まで1階下降。挑戦者は回復し、マスターは戦闘後のHP/MPを保持する。今回から消費したスキルMPもこの既存ルールで保存される。
- EXP・レベルアップ・連勝・直近結果・ドロップ・クールダウン・行ロック・認証/CSRF・履歴保存・戦闘画面を維持。回帰後の闘技場HP/MP回復もステップ4のまま。
- プリセット残回数・状態異常・バフは戦闘内のみで、設定の使用回数や永久習得レコードを書き換えない。
