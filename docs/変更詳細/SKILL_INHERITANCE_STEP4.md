# ステップ4：回帰時の永久スキル継承（2026-11-17）

作業ブランチ `feature/skill-inheritance`、開始HEAD `1ca842a`。ステップ3-C成果物は開始時点で統合済みだった。今回Gitのcommit/push/mergeやブランチ変更は行っていない。

## 新しい挙動

- 回帰確定時、直前の職業の未永久習得スキルから等確率で1種類を抽選し保存。その後、必ず放浪人になる。各職業の既存5種類を使用し、スキルの追加・倍率変更はしない。
- 5種類すべて習得済みなら抽選せず正常に回帰。永久習得数にアプリ側の上限はなく、現在の全35種類も保存できる。
- 使用可能スキルは「現職の固有スキル」と「永久習得」の和集合。現在の職業固有スキルを永久習得する必要はない。職業が変わっても習得記録は残る。
- 戦術画面の候補・POST認可・探索エンジンが同じ認可関数を使用する。永久習得数・由来を画面表示。最大5枠・既存MP/発動率/使用回数/パッシブの扱いは維持。
- 回帰や職業変更で使えなくなった既存プリセットは削除しない。探索時に無許可スキルと範囲外スロットを除外する。再び使用資格を得た場合、その記録を利用できる。

既存の闘技場エンジンはスキルを実行しない通常攻撃専用。今回、闘技場へのスキル戦闘の追加はしていない。未完成のフロストアーマー・浄化・リザレクも抽選対象の5種類に含むが、効果の独自補完はしない。転職画面の新設も対象外で、職業変更後の資格判定・保存継続をテストしている。

## 保存・マイグレーション

`Character.permanent_skills`を`battle.Skill`へのManyToManyFieldとして追加する。

`accounts.0021_character_permanent_skills`は`accounts.0020`と`battle.0017`に依存し、`accounts_character_permanent_skills`中間テーブルを作る。キャラクター/スキル外部キーと、両者の組合せのDB一意制約をDjangoが生成する。同じ関係のaddは重複を作らず、直接の重複INSERTもDBで拒否される。

既存キャラクターの能力・職業・回帰数・プリセットを移行時に変更しない。既存/新規とも永久習得は空から始まる。過去の回帰分を遡って抽選しない。既存キャラクターも次の正常な回帰時から継承する。

dry-runでAddField一件のみであることを確認し、その内容のマイグレーションファイルを作成した。**通常DB・本番DBには適用していない。** テストDBでは自動適用して検証する。導入時には別途承認された環境でこのmigrationが必要。

## 二重実行・例外・認可

回帰は既存の`transaction.atomic`内でCharacterを`select_for_update`し、ロック後のLv100条件を判定する。未習得抽選・関係保存・職業リセット・全能力/HP/MPの更新・闘技場HP/MP回復を同じトランザクションで扱う。例外時は一括ロールバック。

二つの独立したログインセッションが同時POSTしても、待機側はLv1になった行を読み、追加回帰・追加取得をしない。プレビューはキャラクターIDと回帰回数に結び付け、以前の回帰のセッションを次のLv100時に再送しても流用しない。導入前に生成した世代情報なしのプレビューは再生成される。

戦術保存も同じCharacter行をロックし、回帰との同時保存を直列化する。全5枠を検証してから書き込み、他人の永久習得を流用したスキルID・未許可スキル・不正IDは保存しない。既存login_required/CSRFを維持する。

## 測定条件とバランス目標

今後の目標はB約10%、C約50%。今回は目標勝率の達成検証・ボス調整・大規模測定を行わない。旧ステップ3の勝率は当時の条件付き結果として保持する。

測定器のprofileに任意の`permanent_skill_codes`を指定できる。未指定は空。準備時に永久習得関係を置き換え、前のシナリオの習得を持ち越さない。未登録コードは拒否する。新しいmanifestの各caseと戦闘JSONLに`permanent_skill_codes`/`permanent_skill_count`を明示する。既存のCSV列・旧manifest/結果は書き換えない。

B/Cは同一profileの種族・育成seed・回帰/Lv・能力/属性配分・装備・永久習得コードを固定して比較する。永久習得数が等しくても組合せが違う条件は別条件。現在の固定B/C戦術を「継承込みで最適」と扱わない。アプリの戦術画面では職業横断で組めるが、測定器の既定B/Cスロット構成自体は従来のまま。
